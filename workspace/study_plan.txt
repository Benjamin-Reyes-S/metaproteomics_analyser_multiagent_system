Study design case: complex_multifactorial

This study employs a complex multifactorial design combining multiple cohorts/studies with conditions (diseased vs. control) and disease subtypes (CD, UC). The analysis plan focuses on rigorous QC, prevalence-based filtering within groups, and a multivariate differential abundance model that accounts for known confounders (study, disease, use_case). Normalization and batch handling will be finalized upon receipt of the actual intensity/abundance matrices. The plan emphasizes transparent handling of missing data and avoids irreversible batch correction in favor of covariate modeling.

QC PLAN
- host/microbial matrices separated: True
- check: sample IDs match metadata
- check: total intensity per sample
- check: missingness % per sample
- check: PCA by condition/study
- check: RLE plots
- check: technical-replicate CV (if applicable)
- check: per-taxon/function coverage
- flag: technical-replicate CV > 0.2 within a condition/batch
- flag: high keratin/contaminant fraction
- flag: missingness > 50% in any group
- flag: total intensity outliers

FILTERING PLAN
- remove contaminants/decoys: True
- minimum unique peptides: None
- prevalence cutoff: None% (within_group)
- filter host/microbial separately: True
- rationale: Filter host and microbial matrices separately to preserve biological signal. Prevalence filtering should be applied within experimental groups (e.g., diseased vs control) rather than across the entire dataset to avoid removing condition-specific features. Contaminants and decoys must be removed prior to normalization.

NORMALIZATION PLAN
- intensity method: unknown
- compositional method: none
- rationale: Normalization method depends on the actual feature matrix (peptide vs protein LFQ intensities). For continuous intensities, log2 transformation followed by median or quantile normalization is standard. Compositional methods (CLR, etc.) should not be applied to continuous LFQ intensities. Will be finalized once the feature matrix is provided.

BATCH ASSESSMENT AND CORRECTION
- confounded with biology: None
- correction method: covariate_in_model
- rationale: 'study' acts as a major potential batch/covariate. It should be evaluated for association with PCA axes and missingness before correction. Modeling 'study' as a covariate in the differential abundance model is preferred over irreversible batch correction to preserve biological variance and avoid overcorrection. Never correct a batch fully confounded with biology.
- validation: PCA before/after correction
- validation: variance explained by batch vs biology
- validation: technical-replicate CVs

DIFFERENTIAL ABUNDANCE PLAN
- applicable: True
- model type: linear_model
- model formula: abundance ~ condition + disease + study + use_case
- paired: False
- missing-value policy: No blind minimum-value imputation. Features with missingness >50% within any group will be filtered. Remaining missing values will be handled via left-censored imputation (e.g., sample-specific minimum) or excluded from model fitting, depending on downstream sensitivity analysis.
- rationale: Complex multifactorial design requires a model that accounts for multiple covariates (condition, disease type, study cohort, use_case). The formula will be adjusted once sample sizes and grouping strategies are confirmed. Missing value policy must address abundance-dependent missingness common in metaproteomics.
- must report: log2 fold change
- must report: 95% CIs
- must report: raw and FDR-adjusted p-values
- must report: number of observations supporting each protein/function
